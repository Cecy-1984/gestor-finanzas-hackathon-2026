# 💰 Gestor de Finanzas Personales

Aplicación web interactiva desarrollada como parte de la **Hackaton Frontend 2026** del Instituto Superior Santa Rosa de Calamuchita.

## 📌 Descripción del proyecto

El Gestor de Finanzas Personales es una aplicación web que permite registrar, visualizar y administrar los movimientos financieros de un usuario, diferenciando ingresos y gastos.

Su objetivo es facilitar el control del presupuesto personal mediante una interfaz sencilla, intuitiva y dinámica.

## 🚀 Funcionalidades

- ➕ Registro de ingresos y gastos.
- 📊 Visualización de ingresos totales.
- 💸 Cálculo automático de gastos totales.
- 💰 Actualización del balance neto.
- 📋 Historial de movimientos.
- 🗂️ Organización de movimientos por categorías.
- 🗑️ Eliminación de transacciones.
- 💾 Persistencia de datos mediante LocalStorage (opcional).

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Tailwind CSS
- JavaScript Vanilla
- LocalStorage
